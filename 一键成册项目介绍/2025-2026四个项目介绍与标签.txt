01 / VIDEO AGENT
中文名：AI 广告短视频制作 Agent

【创作方向】
AI 创作

【作品类型标签】
AI 视频 / Web 工具 / 程序 / UI / UX / 交互设计 / 动效 / 实验作品

【项目介绍】
VIDEO AGENT 是一个以自然语言为入口的广告短视频制作系统，也是我将视觉判断、广告制作经验与 AI Agent 工程结合的一次实践。传统 AI 视频生产往往需要在脚本、人物设定、提示词、关键帧、视频生成、剪辑与质检之间反复切换，过程分散，结果依赖随机尝试，修改时还容易丢失上下文。我把这些环节重新组织为一条可视化工作流：用户用一句话描述目标，Agent 读取品牌资产与制作规则，将需求拆解为脚本、人物、镜头、声音和验收任务，并在脚本、人物锚定、关键帧、品牌贴标与版本选择等关键节点等待人工确认。对于局部问题，系统只重跑对应镜头，而不必推翻整条视频；每轮脚本、图片、片段、成片和质检记录都会进入同一条可追踪版本链。项目以 YANSHI 矿泉水广告完成端到端验证，从十个关键帧、人物一致性和动态贴标，到抽帧、转写、响度及成片检查，都保留了过程证据。通过流程自动化，原本约四小时完成一条视频的工作，可提升至约一小时完成五条，同时让创意判断、修改范围与交付质量保持可控。这个项目展示了我把复杂生产拆解为界面、规则与协作节点，并将设计方法转化为可运行工具的能力。

【核心卖点】
一句话启动完整制作流程 / 效率提升约 20 倍 / 人工确认保持质量可控 / 局部重跑 / 全程版本可追踪

02 / ONE-CLICK BOOK
中文名：一键成册

【创作方向】
AI 创作

【作品类型标签】
Web 工具 / 程序 / UI / UX / 交互设计 / 画册 / 书籍版式 / 摄影 / 实验作品

【项目介绍】
ONE-CLICK BOOK 是一个面向图片与文字内容的 AI 自动排版成册工具，也是我对编辑设计流程的一次系统化重构。传统画册制作需要先整理素材、判断叙事顺序，再在专业软件中反复建立网格、调整开本、处理跨页关系并检查印刷规范；这套流程门槛高、耗时长，大量精力被消耗在重复操作上。我将编辑设计中的素材分析、内容编排、版式规则、页面编辑和导出预检转化为可以在浏览器中执行的工作流。使用者只需导入照片与文案，选择合适的版式方向，系统便会分析图片比例、视觉重心与内容关系，自动组织顺序并生成整本册子的首次排版；随后仍可在预览和编辑页面中重新排序、替换图片、调整文字与版式，最后完成审核并导出可用于分享或印刷的 PDF。项目不依赖特定设备和专业排版软件，降低了非设计用户制作画册的门槛，也把原本需要数小时甚至数天的素材整理与逐页搭建压缩为分钟级初稿。两套旅行写真集作为实际输出，验证了系统在不同图片数量、叙事节奏和页面组合下的适应能力。这个项目体现了我对书籍版式、信息层级、交互流程与前端工具构建的综合理解，也说明设计自动化并非取消设计判断，而是把可复用的专业规则交给系统执行，把时间留给内容选择和最终审美决策。

【核心卖点】
图片和文案直接成册 / 分钟级生成初稿 / 无需专业软件 / 跨设备使用 / 可继续编辑 / 支持 PDF 与印刷预检

03 / AI STYLE STUDIO
中文名：AI 画风实验室

【创作方向】
AI 创作

【作品类型标签】
AI 图像 / Web 工具 / 程序 / UI / UX / 交互设计 / 图形设计 / 实验作品

【项目介绍】
AI STYLE STUDIO 是一个将设计师的风格判断转化为可选择、可比较、可复用规则的 AI 视觉生成工具。常见的 AI 生图流程高度依赖模型选择、提示词经验与反复抽卡，同一需求在不同批次中容易出现画面语言漂移，使用者也很难准确描述自己想要的视觉风格。我从视觉设计而不是参数面板出发，将模型、隐藏提示词、构图方式、材质、色彩、光线和审美判断整理为 100 余种可直接调用的风格，把复杂技术封装成清楚的风格库。用户先选择视觉语气，再输入文字、图片或图文组合；系统自动识别文生图与参考图编辑任务，匹配对应的生成策略，并将结果放回统一画布中比较、查看和下载。工具的重点不是增加更多随机选项，而是让风格选择先于提示词工程：通过预设规则减少模型测试和提示词调整时间，使同一项目的多张图像保持更稳定的品质与风格一致性。配套的百张高质量实验图像既是风格研究档案，也是对系统覆盖范围的验证。这个项目展示了我在视觉趋势研究、风格拆解、生成控制、设计系统、交互界面和 Web 产品实现方面的能力，也体现了我对 AI 视觉生产中“降本增效”的理解——用设计定义结果标准，用结构化规则降低不可控性，让高质量视觉从偶然命中变为可以重复调用的生产能力。

【核心卖点】
100+ 可调用风格 / 风格选择先于提示词 / 支持文字、图片与图文输入 / 减少反复抽卡 / 提高跨批次质量与风格一致性

04 / NEW CELESTIAL ARCHIVE
中文名：新-天象图库

【创作方向】
视觉设计

【作品类型标签】
信息可视化 / 交互设计 / Web 工具 / 程序 / UI / UX / 图形设计 / 实验作品

【项目介绍】
NEW CELESTIAL ARCHIVE 是一个围绕陨石建立的三尺度交互数据档案，也是我把传统平面信息设计扩展为数字体验的一次实践。面对分散在天文文本、科学表格、历史记录与三维模型中的复杂资料，我先进行数据清洗、分类、量化和信息架构设计，再以“宇宙—地球—物质”三个连续尺度重新组织内容。宇宙尺度展示太阳系小天体的轨道、族群与光谱关系，让用户观察陨石来源与天体运动；地球尺度整理 45,716 条历史陨石记录与撞击结构，通过地图、筛选和比较呈现坠落、发现及空间分布；物质尺度继续放大到矿物、晶系和透明晶体，并使用 WebGPU 实时渲染八类晶体，模拟透光、折射与色散。三个尺度不是彼此分离的页面，而是一条从宏观环境进入地表记录，再抵达微观结构的连续视觉叙事。项目将原有信息图与自制 STL 晶体模型转化为可缩放、可比较、可持续更新的网页系统，使高密度科学信息不再依赖线性阅读，而能通过探索建立理解。它的价值不仅是呈现陨石知识，更在于证明代码与 AI 可以扩展视觉传达的维度：把大量文本和数据转化为关系、空间、运动与材质体验。该项目集中展示了我在数据分析、信息架构、视觉叙事、三维表现、交互可视化与前端实现方面的综合能力。

【核心卖点】
宇宙—地球—物质三尺度探索 / 45,716 条历史记录 / WebGPU 实时晶体渲染 / 高密度信息可比较 / 数据档案可持续更新
